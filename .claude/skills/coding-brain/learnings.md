# Coding Brain — Learning Log

Cross-project lessons that make the next project go better. One line each, newest
on top. Tag `[YYYY-MM-DD · project]`. Only durable, reusable lessons — a gotcha, a
preference, a tool that worked, a trap. Project-specific facts go in that project's
CLAUDE.md, not here. Merge/prune near-duplicates; keep this sharp, not long.

## How to add a lesson

At the end of real work, append under "## Lessons": `- [date · project] <one line>`.
Ask: would this help a *different* project next time? If not, it belongs in CLAUDE.md.
