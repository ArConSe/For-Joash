# ArConSe Brand Kit — UI standard

All applications built for **ArConSe Industrial Corporation** follow this visual
identity. No deviations unless a project's `CLAUDE.md` explicitly overrides.

## Color palette

| Role | Name | Hex | Usage |
|---|---|---|---|
| Primary | ArConSe Orange | `#FF6400` | Nav bar, primary CTAs, highlights |
| Primary Dark | Burnt Orange | `#E05500` | Hover / active states, gradients |
| Dark Base | Navy | `#0C1A47` | Hero sections, dark backgrounds, footer, primary buttons |
| Light Base | Cream | `#FDF9F0` | Light section backgrounds, cards |
| Text on Dark | Ivory | `#FFFFF0` | Headings/text on navy/dark backgrounds |
| Body Text | Charcoal | `#333333` | Default body text on light backgrounds |
| White | White | `#FFFFFF` | Page and card backgrounds |

## Typography

| Role | Font | Weight | Usage |
|---|---|---|---|
| Display / Hero | Anton | 500 | Large hero headlines, impact statements |
| Headings | Antonio | 700 | H2, H3, nav links, button labels |
| Body | Roboto | 400 | Body copy, descriptions, form fields |
| Body Emphasis | Roboto | 600 | Subheadings, labels, emphasized text |
| Secondary | Roboto Slab | 400 | Pull quotes, callout text |

## Design language

- **Style:** industrial, bold, high-contrast — construction and infrastructure feel.
- **Layout:** section-based, alternating backgrounds (Navy ↔ Cream ↔ Orange).
- **Components:** card grids (3-col products, 2-col services), full-width hero sections.
- **Spacing:** generous section padding, clean whitespace between cards.
- **Imagery:** real project photography — infrastructure, construction, solar, water.
- **Tone:** professional, credible, solution-focused. No playful or casual UI copy.

## Do not

- Use purple, pink, or pastel tones anywhere in the UI.
- Use generic/system fonts for headings — always Anton or Antonio.
- Mix more than 2 section background colors in a single view.
- Use rounded pill buttons — sharp or ≤ 4px border-radius only.
- Add decorative icons unrelated to construction, engineering, water, or energy.
